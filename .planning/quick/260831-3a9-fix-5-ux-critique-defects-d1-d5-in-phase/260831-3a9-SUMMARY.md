# Quick Task 260831-3a9: Fix 5 UX-Critique Defects (D1-D5) Summary

**Fixed 5 real UI defects an independent UX critique found in Phase 9's upload/register-key/rotate-delete screens: a dead-end copy modal, a self-contradicting footer, a mislabeled evidence frame, an invisible confirmation affordance, and a stale visual-regression baseline — plus closed REVIEW.md's open parity-critique obligation.**

## Accomplishments

- D1: the register-key manual-fallback modal now has a "c copy public key" affordance, gated by one predicate shared with its key binding (`registerKeyCopyable()`), so a hint can never exist without a working binding or vice versa.
- D2: the register-key status line now reads either "registration ran when this opened" or "nothing was registered" depending on actual state — never both contradictory claims at once — and the action-menu row now discloses the immediate provider mutation ("Register key with provider now (u)") before it is pressed.
- D3: REVIEW.md's Per-Focal-point judgement table no longer cites `create-flow-upload-checkbox-disabled.txt` as DISABLED-state evidence (it's byte-identical to the UNAUTH frame); it now names the real unit test, `TestUploadCheckboxRowIsExactlyOnePhysicalLine`, confirmed by reading it first.
- D4: the live rotate delete-offer now shows `↑↓/Tab choose · Enter confirm` in the footer and suppresses the shared ceremony's `Done (Enter)` label while the choice is unresolved — one unambiguous Enter affordance at a time, implemented as an opt-in field on a local copy so no other ceremony's rendering changed.
- D5: all 13 tracked Phase 9 PTY reference frames re-promoted from a freshly cleared capture directory, absorbing the D1/D2/D4 render changes plus the pre-existing `c3af8b9` ellipsis-truncation fix that had never been re-baselined.
- Task 6: full gate battery (build, `-race` unit tests, lint, two e2e filters, screenshot-tagged tests) run and re-verified green after Task 7's docs commit — exact counts recorded below.
- Task 7: REVIEW.md's "Parity critique — PENDING" placeholder replaced with a completed section citing the 5 real fix commits by SHA and recording the 5 improvements verbatim as deliberately deferred.
