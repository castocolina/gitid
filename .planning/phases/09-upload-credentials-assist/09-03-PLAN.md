**Two decisions Claude's Discretion covers, resolved here with rationale:**

1. **Inventory shape (09-RESEARCH.md Open Question 1):** full JSON parsed with
   stdlib `encoding/json` in Go, NOT `gh api --jq` filtering. Rationale: the
   codebase has no third-party JSON dependency and no `--jq` precedent anywhere,
   and a `--jq` expression couples the argv to a specific response shape that
   changes silently on the provider's side, whereas an unrecognized field in a Go
   struct is simply ignored.
2. **Inventory failure posture (D-15, restated as code):** `Inventory` returns
   `([]ExistingKey, error)`, and every caller treats a non-nil error as "no dedupe
   information available" — never as a reason to stop. The degraded path is
   surfaced through `UploadRunView.InventoryDegraded`, the field plan 09-02 already
   declared.
