## Cross-AI review corrections folded into this plan (09-REVIEWS.md)

This wave was rated LOW risk and its structure is unchanged. Three small corrections:

**(R21) The byte-exact test is the authoritative copy contract; the Makefile gate is
a secondary source-presence guard.** `make gate-copy-freeze` proves only that a
string appears SOMEWHERE under the scanned roots — a comment or a dead declaration
could satisfy it. `TestFrozenUploadCopy` is what actually pins the value. The two are
not equally strong and this plan must not describe them as if they were; Task 2's and
Task 3's criteria now say which is which.

**(R22) An amendment path exists for operational copy discovered to be wrong.** This
wave freezes complete user-facing sentences for scope diagnostics and provider
remediation before any of that code exists. If Waves 3 or 8 discover that real
`gh`/`glab` behavior makes a frozen remediation sentence inaccurate, the correct
response is a REVIEWED amendment — a scoped `design.go` edit plus matching updates to
`TestFrozenUploadCopy` and the `gate-copy-freeze` list, recorded in that plan's
SUMMARY as a copy amendment with the observed provider behavior that motivated it —
not silently rendering something else, and not leaving inaccurate guidance in place
because it is frozen. Task 2's section comment records this rule so a later executor
finds it where the constants live.

**(R23) Nothing in this wave may freeze the checkbox as a `u`-only affordance.** Plan
09-02 resolves the checkbox into a real Tab-ring focus slot that is also
click-reachable; the `u` key is a shortcut, not the only way in. Task 1's key-table
bullet already says this — keep it that way, and do not let the key-allocation row's
brevity imply otherwise.
