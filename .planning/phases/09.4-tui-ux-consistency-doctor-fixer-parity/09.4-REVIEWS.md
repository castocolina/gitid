### Overall Assessment

**Verdict: REQUEST CHANGES. Overall risk: HIGH.**

The architecture is sound: the plans correctly identify the full tab-routing blast radius,
preserve Health's unfiltered findings while retaining Fixer's guarded write ceremony, and cover
the most dangerous silent failure in `checkFixBatchHalt`. However, execution should not begin
yet. There are four blocking process/test defects:

- All four plans omit the mandatory `cross_ai: true` frontmatter field, despite the repository
  explicitly forbidding execution without it (`.planning/ONESHOT.md:23`, `:97`).
- Plan 01 knowingly closes Wave 1 with `make test-e2e` failing, contrary to the every-wave
  green-gate rule (`09.4-01-PLAN.md:456`, `.planning/ONESHOT.md:61`).
- Plan 02 does not actually compile the screenshot-tagged `internal/screenshot` tests and has
  an impossible no-`t.Skip` criterion.
- Plan 04 explicitly calls for committing a failing test, violating the buildable-commit rule
  (`docs/agent-instructions/engineering.md:24`).

The UI-SPEC state is also inconsistent: `.planning/STATE.md` says it is approved, while the
specification itself still has every checker box empty and says `Approval: pending`
(`STATE.md:8`, `09.4-UI-SPEC.md:370`).

### Plan 01 — Doctor merge core

**Summary:** Correct structural model for reversing FIX-02. Accurately combines Health's
all-findings scope with Fixer's ceremony state and accounts for the fixed-size screen array,
navigation keys, deep-link routing, and silent concrete-type assertions. Main defect is wave
atomicity: it intentionally leaves required downstream gates red.

**Strengths:**
- Tab arithmetic is correct: the live shell has six members (`internal/tuikit/frame.go:58`),
  and the binding spec correctly places `TabDoctor` at key 4, moving Git Ignore to key 5
  (`09.4-UI-SPEC.md:56`).
- Catches all three routing mechanisms — keyboard/mouse identity deep-links plus the header
  chip — as genuinely independent sites (`internal/tuikit/app.go:453,515,554`).
- Selects the correct data source: Health's `findings` returns all ordered findings
  (`internal/tuikit/health_screen.go:102`); Fixer currently causes the contradictory count by
  narrowing to `fixableFindings` (`internal/tuikit/fixer_screen.go:110`).
- Write gate preserved correctly: `f` checks `sel.Fixable`, `F` builds its queue from
  `fixableFindings` (`internal/tuikit/fixer_screen.go:220`).
- Correctly elevates the silent type-assertion hazard in `checkFixBatchHalt`, which depends on
  two `fixerModel` assertions that can fail without a compile error (`internal/tuikit/app.go:314`).

**Concerns:**
- **HIGH** — Wave 1 is deliberately left red: the plan expects both E2E and visual gates to
  fail after completion (`09.4-01-PLAN.md:456`), contrary to the repository's every-wave green
  gate requirement (`.planning/ONESHOT.md:29,61`).
- **MEDIUM** — The named tracer `TestDoctorMergedListShowsEveryFinding` checks only list
  membership/count (`09.4-01-PLAN.md:220`); Health already displays all findings and the
  all-findings count (`internal/tuikit/health_screen.go:138`) — the actual merge property only
  emerges combined with the separate `f` assertion.
- **MEDIUM** — The proposed source-reversion proof does not simulate the silent failure: after
  `fixerModel` is deleted, reverting an assertion to `fixerModel` produces a compile error, not
  `ok == false` at runtime (`09.4-01-PLAN.md:391`), so it does not prove the guard catches the
  mechanism at `internal/tuikit/app.go:315`.

**Suggestions:**
- Move the E2E navigation rewrite and minimum screenshot-registry correction into Plan 01, or
  merge Plans 01 and 02 into one wave.
- Make the tracer one test that proves all three properties on the same tab: all findings
  displayed, a fixable selection opens the ceremony, a non-fixable selection does not.
- Demonstrate the type-assertion guard by temporarily asserting an existing wrong concrete
  model (e.g. `globalGitModel`) so the code compiles and fails through the intended silent
  `ok == false` path.

**Risk:** HIGH until wave atomicity is fixed; MEDIUM afterward.

**Concerns:**

  `./cmd/gitid/...` (`Makefile:774`) — those internal tests are never compiled.
- **HIGH** — A renamed public capture function has an omitted caller: `createflow_packet_test.go`

- **MEDIUM** — Geometry coverage omits three strip-bearing states: `subTabStrip()` also
