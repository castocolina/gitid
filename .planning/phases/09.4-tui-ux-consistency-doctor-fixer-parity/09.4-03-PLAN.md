## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mouse click / keypress -> option selection set -> the apply ceremony -> `Backend.Persist` | the boundary where a rendering change can cause a DIFFERENT option than the user intended to enter the write set |
| `OptionState` from the classifier -> the row renderer's `Selectable()` gate | the classifier decides what may be written; the renderer must not widen that decision |
