# Phase 9.7 — UI Design Contract

Consistency retrofit of the New-Identity wizard (steps 0–2 only). Not a new
surface. Step 3 Review/ceremony and the Register-key modal are out of scope.

Authority: compiled `cmd/gitid` vs `cmd/gitid-dummy` through real PTY.
Dummy remains the locked interaction reference; this phase only adds grouping,
typed proof entries, persistent warnings, fixed input width, and reserved hints.

## Rules

| ID | Rule |
|----|------|
| G-1 | Default grouping is a bold header plus a blank line (D-01). Use `PreviewBlock` only if the 30-row pane still fits after D-08 measurement. |
| G-2 | Step 0: Key cluster separated from SSH rows above. Step 1: Demo-failure control separated from warning/upload. Step 2: author fields get the same header treatment Match strategy already has. |
| T-1 | Success/warning/error keep existing `styleHealthy`/`styleWarning`/`styleError` plus a blank line between differently typed blocks (D-03). No new colors. |
| T-2 | `ReachableNotUploaded`/`keyUnused` is appended to the proof transcript and stays for the rest of the wizard session (D-04). |
| T-3 | `proofText()` is a list of typed entries (info/success/warning/error), colored at render time — not regex on the concatenated string (D-05). |
| I-1 | Every wizard text input has a fixed `SetWidth` sized to its longest realistic value (D-06). |
| I-2 | Every wizard field reserves its hint row even when blank (D-07). |
| R-1 | D-08: measure steps 0–2 with G-1, T-1, T-2, I-2 applied together against the 30-row pane. Record trims. Fail the plan if Continue/Skip falls off the frame. |

## Out of scope

Step 3 ceremony, Register-key modal, classifier packages, real `~/.ssh`/`~/.gitconfig` writes beyond existing wizard commit paths.

## Approved base states

1. Step 0 with Key header visible and SSH fields above it.
2. Step 1 with warning still present in the proof viewport after advancing.
3. Step 2 author cluster with reserved hint rows and no layout jump on focus.
4. Typed proof entries: one success and one warning colored distinctly.
