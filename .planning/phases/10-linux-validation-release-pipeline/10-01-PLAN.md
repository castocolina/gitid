<objective>
Stand up `internal/version` — the D-09 hybrid version-resolution package — and wire it end-to-end: the Makefile's linker flags, `cmd/gitid`'s `--version` output, a new `gitid version` (+ `--json`) subcommand, and a minimal, additive TUI help-overlay line. This is the phase's tracer: the thinnest slice that proves version stamping works correctly across every layer before Phase 10's release pipeline (Plan 10-04) and Linux-validation CI job (Plan 10-02) build on top of it.

Purpose: BUILD-03 requires `gitid --version` to be truthful and build-stamped on a version tag; D-09/D-10/D-11 specify exactly how. Getting this wrong quietly ships a binary that lies about its own version — the single most load-bearing fact a release pipeline publishes.
Output: `internal/version` package (Resolve() + Info), Makefile LDFLAGS retargeted to it, `cmd/gitid`'s `--version` and new `version` subcommand consuming it, TUI help overlay optionally showing it.
</objective>
