## Trust Boundaries

| Boundary | Description |
|---|---|
| argv flags → destructive operations | a flag combination selects an irreversible act with no screen in between |
| non-interactive automation → the write chokepoint | scripted use has no human to catch a wrong target |
| documentation → acceptance | a matrix that drifts from the tree makes a false parity claim |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
