Split the work between the package that owns the reserved-path registry and the package that owns key material, so neither imports the other.

In `internal/sshconfig/include.go`: add an exported constant `ArchiveDirName` with the value `gitid-archive` and an exported `ArchiveDir(sshDir string) string` returning `filepath.Join(sshDir, ArchiveDirName)`. Extend `ReservedPaths` to return the archive directory and the `*` glob directly inside it, appended AFTER the existing two `config.d` entries so the existing ordering assertion in `include_test.go` stays a prefix. Extend `IsReservedPath` so the archive directory itself and any file whose `filepath.Dir` is the archive directory both report true. In a new `internal/keygen/archive.go`: define `type ArchivedPair struct { PrivatePath, PublicPath string }` and `func ArchiveKeyPair(archiveDir, privPath, pubPath, stamp string) (ArchivedPair, error)`. The archive directory is passed IN as a parameter so `internal/keygen` never imports `internal/sshconfig` — the composition root resolves it via `sshconfig.ArchiveDir`. Add package-level mode constants `archiveDirMode` 0o700 and reuse the existing private/public key modes. Implement as: create the directory with `os.MkdirAll` then `os.Chmod` to the explicit mode (never inherit the umask); build each destination as the source basename plus a dot plus `stamp`, inserting `.pub` before the stamp for the public half; copy each file with an exclusive-create open so an existing destination is a hard error, matching `internal/filewriter`'s `copyFileExclusive` idiom; then remove the sources. Order matters: copy BOTH halves first, then remove both, so a mid-operation failure never leaves the pair half-archived. On any error after a partial copy, remove the copies made so far before returning.

Choose the stamp convention explicitly and document it on the function: the caller supplies it, and the production caller uses the same `UnixNano` decimal string `filewriter.backupExistingTarget` uses — one timestamp convention across the project, never the ISO-8601-with-dashes shape `tuikit.NewBackupPath` produces (that is a dummy-fixture display convention, per 05-RESEARCH.md's Don't Hand-Roll table).

In `internal/identity/inventory.go`: make `listKeyFilesRealForHome` skip any path under the archive directory. The current glob is non-recursive so it cannot reach into the directory today, but the guard is the durable registration: enumerate, then drop any match for which `sshconfig.IsReservedPath(sshDir, match)` reports true. This is what makes the doctor's Class 3 unused-key check and its permission check structurally blind to archived material.

In `internal/doctor/checks/orphans_test.go`: add a regression test that plants an archived key inside the archive directory of a fake home, builds the doctor deps through the same enumeration path production uses, runs `CheckOrphans`, and asserts zero findings mention the archived path. Name it so its intent is obvious to a future reader who hits the destructive `--fix` loop again.

## Trust Boundaries

| Boundary | Description |
|---|---|
| in-memory key material → archive directory | private key bytes cross onto disk at a new location |
| caller-supplied email → allowed_signers principals field | untrusted-ish text is interpolated into a trust file |
| provider hostname → managed block sentinel name | a name selects which block is deleted |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-06 | Information Disclosure | archived private key | high | mitigate | Explicit 0600 on the archived private key and 0700 on the directory, set via `os.Chmod` after creation so the process umask cannot widen them; asserted by a mode test. |
| T-05-07 | Tampering | archive destination collision | medium | mitigate | Exclusive-create copy; an existing destination is a hard error and the source is left intact. |
| T-05-08 | Elevation of Privilege | comma injection into allowed_signers principals | high | mitigate | The append path builds its line only through `AllowedSignersLine`, which rejects a comma-bearing email (CR-18); a test asserts no file is written on rejection. |
| T-05-09 | Tampering | wrong insteadOf block removed | high | mitigate | Removal is keyed by `ProviderRewriteBlockName`, never by a substring or the global baseline name; a test asserts the sibling provider block and the global block survive. |
| T-05-10 | Denial of Service | doctor `--fix` deleting archived keys | high | mitigate | Archive directory registered in the single reserved-path registry AND excluded from key enumeration; a doctor regression test asserts zero findings. |
</threat_model>
