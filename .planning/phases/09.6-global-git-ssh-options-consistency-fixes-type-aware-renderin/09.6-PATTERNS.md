// Source: internal/tuikit/views.go:590-595 — Global Git — VERIFIED
func (o GlobalGitOptionView) Selectable() bool {
	if o.ProbeError != "" || !o.PolicyBacked || !o.HasWritableMember {
		return false
	}
	return o.State == GlobalGitNeedsAction
}

// Source: internal/tuikit/views.go:372-377 — Global SSH — VERIFIED
func (o GlobalSSHOptionView) Selectable() bool {
	if o.ProbeError != "" || !o.WritableToHostStar {

}

**Analog (enum cycle):** `gitForm.handleEdit`, Match-strategy radio group — `internal/tuikit/identities.go:945-962` and `:1050-1062`.

**Divergence from literal precedent:** the wizard renders all values as always-visible radio dots (fixed-height single form pane). The Options screen's master list is scrolling (~17 rows) — render the CLOSED (non-editing) row as single-line "current value only"; render the cycle-through-values interaction in the DETAIL PANE (the same slot the fallback-author text fields already occupy), triggered by `e`, not inline in the master list.

**Analog (text field):** `gitFallbackFieldLine`, already wraps `formFieldLine`/`helperLine` for the ONE existing text row.

```go
// Source: internal/tuikit/globalgit.go:2129-2138 — VERIFIED
func gitFallbackFieldLine(label string, input textinput.Model, editing, selected bool) string {
	if editing {
		return formFieldLine(label, input, true, false)
	}
	if selected {
		name := styleBold.Render(padRight(label, 16))
		return " " + styleFaint.Render("▸ ") + name + DefaultTheme.FieldBlurred.Render("["+input.Value()+"]")
	}
	return formFieldLine(label, input, false, false)
}
```
Reuse this shape directly for any newly-text-typed row; `formFieldLine`/`helperLine` themselves live at `internal/tuikit/identities.go:456,469`.

**Key-gesture collision to guard against (both files):**
```go
// Source: internal/tuikit/globalgit.go:1108-1115 — VERIFIED
switch key {
case "left", "right":
	if key == "right" {
		m.subTab = ggitNextSubTab(m.subTab)
	} else {
		m.subTab = ggitPrevSubTab(m.subTab)
	}
	return keyResult{model: m, handled: true}
```
This unconditional `left`/`right` case sits at the top of the generic switch in both `globalgit.go` (~1108-1115) and `globalssh.go` (~1126-1131, cited via grep). The new enum-editing mode's `←`/`→` cycle MUST be intercepted BEFORE this, mirroring the existing `fieldEditing` early-guard shape:
```go
// Source: internal/tuikit/globalgit.go:958-981 — VERIFIED (existing precedent for the guard POSITION)
if m.fieldEditing {
	switch key {
	case "esc", "enter":
		m.fieldEditing = false
	...
	}
}
```

**Existing gesture to rewire (Pitfall 4 — explicit task, not a side effect):** today the fallback-author field triggers on **Enter** (`internal/tuikit/globalgit.go:1191-1202`, `case "enter": ... m.fieldEditing = true`), and Esc/Enter are currently IDENTICAL while editing (`globalgit.go:958-981`, both just `m.fieldEditing = false`, no revert). CONTEXT.md's `e`-triggers / Enter-commits / Esc-dismisses contract is a genuine behavior change to this already-shipped row — decide explicitly whether "dismiss" means revert-to-prior-value (needs a pre-edit snapshot, new mechanism) or exit-keeping-typed-value (today's behavior, cheaper).

### `cmd/gitid/wiring.go` — `AllGitSetKeys` exclusion-set fix (UXG-03)

**Analog:** itself, in-place fix — the wrong lookup is called; the right one already exists in the same package boundary.

**Current (buggy) code** (`cmd/gitid/wiring.go:2123-2155`, verified this session):
```go
func (b *realBackend) AllGitSetKeys() ([]tuikit.GitSetKeyView, error) {
	if b.initErr != nil {
		return nil, fmt.Errorf("git probe failed: %w", b.initErr)
	}
	keys, err := globalgit.AllSetKeys(globalgit.BuildProbeDeps(b.fragmentDir))
	if err != nil {
		return nil, fmt.Errorf("git probe failed: %w", err)
	}
	out := make([]tuikit.GitSetKeyView, 0, len(keys))
	for _, k := range keys {
		_, policyBacked := globalgit.PolicyFor(k.Key)
		out = append(out, tuikit.GitSetKeyView{
			Key: k.Key,
			Value:        b.displayMessage(tuikit.SanitizeDisplayValue(k.Value)),
			Scope:        k.Scope,
			Origin:       b.displayPath(k.Origin),
			PolicyBacked: policyBacked,
			ValueCount:   k.ValueCount,
		})
	}
	return out, nil
}
```

**Bug:** `globalgit.PolicyFor` (`internal/globalgit/policy.go:250-257`) matches the Policy row's DISPLAY key (e.g. `"core.autocrlf / core.eol"`), never equal to a raw member key (`"core.autocrlf"`) that `AllSetKeys` returns — bundle members are never excluded, silently duplicated on both sub-tabs.

**Fix (three sources, per RESEARCH.md Pitfall 2):**
1. Replace `globalgit.PolicyFor(k.Key)` with `globalgit.PolicyForMember(k.Key)` (`internal/globalgit/policy.go:280-287`) — already built for exactly this collision-detection need, matches raw member key shape.
2. Add a new local constant/slice for the two literal fallback-author keys (`"user.name"`, `"user.email"` — `internal/gitconfig/fallbackauthor.go:85`), since the fallback-author Policy row has `Members: nil` (`internal/globalgit/policy.go:154-159`) and is invisible to ANY member-based lookup. Do not reuse `internal/identity.CopiedFieldGitEmail` (`internal/identity/clone.go:22`) — different package, different semantic purpose.
3. Compute `policyBacked` (or a new `excluded` bool used to filter the `out` slice, per UXG-03's "excludes" wording — not just tags) from the union of (1) and (2), THEN skip appending excluded keys.

**Test discipline:** write a real-machine test (Policy table + fallback-author write path together, PROP-01/09.5-01 precedent style) asserting zero overlap between the Options sub-tab's key set and `AllGitSetKeys`'s returned key set — a fixture-only test would not catch a real omission.

## Shared Patterns

### Type-aware row rendering (checkbox vs. inline-value)
**Source:** `internal/tuikit/globalgit.go:1957-1971` (checkbox column, `Selectable()`-gated) — apply the SAME gating logic (only `Selectable()` rows get an interactive glyph) when deciding whether a row shows `[✓]`/`[ ]` (bool/bundle) vs. current-value-inline (enum/text). Apply to both `globalgit.go` and `globalssh.go`.

### Warning-glyph guard (`!` fires ONLY on `NeedsAction`)
**Source:** both `globalgit.go:1972-1981` and `globalssh.go:1499-1511` — apply identically to both files, same commit, same shape of fix (narrow `case`, add explicit no-glyph branch for `Differs`/`SetButDiffers`).

### Frozen-copy discipline for the "Set keys" → "Other keys" rename (UXG-04)
**Source:** `internal/tuikit/design.go:892` (`PropsGitSubTabLabel`), `internal/tuikit/globalgit.go:70` (`ggitFooterCycleLabel`, literal `"Options / Set keys"`), `Makefile:604` (`gate-copy-freeze` frozen-string grep for literal `'Set keys'`).
**Apply to:** the same commit MUST update all four: the two Go string constants, `Makefile:604`'s frozen string, and the 3 unit-test (`internal/tuikit/globalgit_test.go`) + 5 real-PTY e2e (`e2e/global_git_pty_e2e_test.go`) occurrences of the literal `"Set keys"` — `make test` depends on `gate-copy-freeze` (`Makefile:420-421`) and will go red otherwise.

### Modulo-wrapping enum cycle
**Source:** `internal/tuikit/identities.go:956-962` — `(idx + len(values) - 1) % len(values)` / `(idx + 1) % len(values)`. Apply to any new enum-typed Options row (`StrictHostKeyChecking`, `merge.conflictstyle`, `diff.colorMoved`).

### Value validation on newly-editable text rows
**Source:** `gitconfig.validateValue` / `gitconfig.ValidateEmail` (already used by `EnsureGitFallbackAuthor`, `EnsureCustomGitKey`) — reuse for any text-typed row's commit path; do not hand-roll a new validator (CR-18 comma-injection fix lives in the existing validator).
