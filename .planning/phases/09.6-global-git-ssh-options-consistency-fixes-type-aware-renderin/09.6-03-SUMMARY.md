# Phase 9.6 Plan 03: Global Git Enum Editor and Override Write Path — SUMMARY

## Objective

Expand plan 09.6-02's proven vertical slice sideways onto Global Git: render the resolved
value on enum and text rows, and give Global Git the same enum editor and override write
path Global SSH already has — by reusing the shared editor, never by writing a second one.

Purpose: Global Git carries ten of the phase's seventeen rows and the only hard
version-gated row. It is the larger half of UXG-01 and the half the user's bug report
actually named.

Output: `merge.conflictstyle` and `diff.colorMoved` editable in place through the existing
ceremony, with the checkbox column provably unchanged and the hard version gate provably
still in force over an overridden value.

## Threat Mitigations

All threat mitigations from the plan's threat register are implemented:

- **T-09.6-14** (tampering, merge.conflictstyle hard gate): The override routes through
  `WriteRequestedValueFor` hard gate (plan 09.6-01). Task 2 behavior Test 8 re-proves it
  from THIS screen's dispatch path with a below-minimum reported git version.

- **T-09.6-38** (spoofing, preview vs. commit): PD35 byte-level assertion in Task 2 behavior
  Test 8: preview diff text contains fallback and NOT the requested value; advisory names
  substitution; committed bytes carry fallback. Commit-only assertions would leave preview
  free to show zdiff3 while gate writes the fallback — consent defect.

- **T-09.6-39** (tampering, scrolled list): Task 2 behavior Test 11 (implicit in Task 3 e2e)
  opens editor with selection off first visible row; asserts it lands on SELECTED row, not
  first visible. This screen's scroll window has separate absolute/visible indices, failure
  mode SSH tracer never exercised.

- **T-09.6-15** (tampering, ceremony dispatch): Task 2 behavior Test 6 asserts with recording
  stub that no-override path calls pre-existing planner and commit; override path calls seam.
  Two paths never both called for one ceremony.

- **T-09.6-16** (DoS, editor guard vs. zero-options): Guard precedes both sub-tab-switch
  sites; Esc always closes editor. Asserted by Task 2 behavior Test 2.

- **T-09.6-17** (tampering, arrow-cycle value set): Cycle indexes only declared values from
  policy table; overlay builder refuses out-of-set value by name (Task 2 behavior Test 9).

- **T-09.6-18** (repudiation, second editor): PD26 forbids porting; Task 2 behavior Test 10
  asserts Git model carries shared editor type; shared type's unit tests exercise both screens.
