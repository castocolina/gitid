## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-typed free text -> tuikit model | the first place in this phase where arbitrary user text, not a curated value-set member, enters an option row |
| typed value -> the Git option-value seam's plan stage -> `~/.gitconfig` managed block | the write boundary; validation happens at the seam, before any ceremony opens |
| the gitid-managed block on disk -> `ReadGitFallbackAuthor` -> the Options row cell | a correctness boundary: the row must report what the managed block contains, not a stale in-session value |
| pre-edit snapshot -> restored field values | a correctness boundary: a stale snapshot would silently discard a previously committed value |
