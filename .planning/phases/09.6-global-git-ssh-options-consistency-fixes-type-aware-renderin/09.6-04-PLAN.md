<objective>
Close the free-text half of type-aware rendering AND fix the read-path defect the user
actually reported: make `ReadGitFallbackAuthor` authoritative for what the Options row shows,
regesture the one text row that already ships, and give `init.defaultBranch` its own free-text
editor validated by git's real ref grammar.

Purpose: the fallback-author pair is where two of this phase's three complaints live at once —
"in option is empty and the second sub view have value" (a read-path bug with a single traced
cause), and "Enter starts editing, and Enter and Esc are indistinguishable once open" (the one
row in the app where the promised gesture set is already wrong today). CONTEXT.md's
uniform-gesture requirement is not satisfiable while that row disagrees with every row plans
09.6-02 and 09.6-03 just built.

Output: one gesture vocabulary across all seventeen rows, an Options row that shows what the
managed block actually contains, and the on-disk config proven byte-identical after a dismiss.
