**4. [Rule 1 - Bug] `parseGLabTokenScopes` silently accepted a top-level JSON array**
- **Found during:** Task 3's own account-free
  `TestRealAccountGitLabScopeCheckRequiresExactMember` test, BEFORE the parser
  shipped (`--- FAIL` on first run, caught and fixed before committing).
- **Issue:** `parseGLabTokenScopes` searched for the first `{` byte and decoded
  from there. For `[{"scopes": ["api"]}]` (a top-level array wrapping a single
  object — the exact shape the pinned contract is supposed to reject), the first
  `{` is the ARRAY's inner element, at index 1; trimming to that byte decoded the
  inner object as if it were the top-level contract, with `]` tolerated as
  trailing noise by `json.Decoder`. This silently ACCEPTED the forbidden shape.
- **Fix:** Search for whichever of `{`/`[` appears first via
  `strings.IndexAny(output, "{[")`; if the first such byte is `[`, reject
  immediately (`ok=false`) rather than trimming past it.
- **Files modified:** `e2e/upload_real_account_gitlab_e2e_test.go`
  (`parseGLabTokenScopes`)
- **Verification:**
  `TestRealAccountGitLabScopeCheckRequiresExactMember/top-level_JSON_array_instead_of_an_object`
  now passes; all 14 sub-tests in that table pass.
- **Committed in:** `d6dbf37` (Task 3) — this bug was caught and fixed before the
  Task 3 commit was made; no separate fix commit exists.
