## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command-line arguments → the write path | User-supplied option names reach the candidate builder. |
| headless invocation → the user's config with no interactive confirmation | The confirmation flag replaces a human. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-24 | Elevation of Privilege | an unrecognised or per-alias option name on the command line | high | mitigate | The write verb resolves names against the policy table and refuses anything not writable to the wildcard block, by name; asserted by a dedicated test. |
| T-06-25 | Repudiation | an unattended write with no backup | critical | mitigate | The backup is taken by the shared commit path and no flag reaches it; the e2e case asserts a backup exists after each of two runs. |
| T-06-26 | Tampering | a CLI-only write path drifting from the screen's | high | mitigate | Both surfaces call the same plan and commit functions; a test asserts the command holds the backend and calls the named method. |
| T-06-27 | Spoofing | a green gate that proves nothing | high | mitigate | Four negative controls plus a hand-verified fail path; the mutation-sensitivity control specifically prevents a vacuously-equal comparison. |
| T-06-28 | Denial of Service | a headless write on a non-terminal without confirmation | medium | mitigate | Refused with an error naming what is missing, per the adaptive-depth convention; asserted by a test. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | accept | No new packages. |
</threat_model>
