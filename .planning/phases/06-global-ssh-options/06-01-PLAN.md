`func EnsureGlobals(existing []byte, explicit map[string]string, goos string) ([]byte, error)` is the ONE entry point:
1. Read the current body from the block named `GlobalBlockName`, or, when absent, from `LegacyGlobalBlockName`.
2. Parse that body into an ordered key/value map, tolerating both the two-space `hostIndent` and the four-space form, and ignoring the `Host *` and `IgnoreUnknown` lines (they are structure, re-rendered below).
3. Overlay platform defaults for ABSENT keys only — existing values always win (D-06). Platform defaults remain `UseKeychain yes` and `AddKeysToAgent yes` on darwin only; `platform.SupportsUseKeychain(goos)` stays the gate.
4. Overlay `explicit` unconditionally — these are the user's confirmed global-SSH fixes and they always win.
5. Render in canonical order: the `IgnoreUnknown UseKeychain` directive as the body's FIRST line, then a blank line, then `Host *`, then the merged keys indented with `hostIndent`, ordered by `Policy`'s declaration order with any unrecognised pre-existing key appended after them so a hand-added directive inside the block is never dropped.
6. Compose with `filewriter.ReplaceBlock(existing, GlobalBlockName, body)`, then `filewriter.RemoveBlock(..., LegacyGlobalBlockName)` so a machine can never end up carrying both names (D-08 adoption).
7. Validate with a `Parse` round-trip before returning, exactly as `Write` already does, and return an error rather than composed bytes when it fails.

Pin the platform contract explicitly in the doc comment, because the review found it undocumented and the current writer's behavior is the opposite:
- the guard directive is emitted UNCONDITIONALLY on every platform, first, because it is inert where the guarded directive is absent and is the only thing that keeps a configuration synced from a mac from hard-erroring on linux (D-11, recipes/ssh-config.recipe's own first-directive pattern);
- a darwin-only key already present in an existing body is PRESERVED on linux, never dropped — dropping it would silently degrade a synced configuration;
- darwin-only DEFAULTS are supplied only when the platform gate allows them;
- the function never returns content in which a previously non-empty globals block became empty or absent.
