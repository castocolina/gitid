<objective>
Prove the whole Phase 6 architecture end-to-end on ONE option, and make gitid own exactly one `Host *` block while doing it.

Purpose: 06-CONTEXT.md's D-06 records a code finding that would silently destroy this phase's work if discovered late — the create ceremony whole-block-replaces the `_global` block on every create, so a naive global-SSH fix is erased by the next identity created. That defect only shows up when a real probe, a real merge, a real write and a real re-read are wired together. This plan wires that single path for real (`HashKnownHosts` — the one option in the D-10 table with no platform guard, no version gate and no per-alias special case), so the architecture is validated on one commit rather than after five layers are already built on top of it.
Output: A live Options sub-tab whose `HashKnownHosts` row shows the machine's real value and provenance and whose apply ceremony performs a real backed-up, idempotent write — plus a single-owner globals module both the create flow and the fix flow call.
</objective>

`func EnsureGlobals(existing []byte, explicit map[string]string, goos string) ([]byte, error)` is the ONE entry point:
1. Read the current body from the block named `GlobalBlockName`, or, when absent, from `LegacyGlobalBlockName`.
2. Parse that body into an ordered key/value map, tolerating both the two-space `hostIndent` and the four-space form, and ignoring the `Host *` and `IgnoreUnknown` lines (they are structure, re-rendered below).
3. Overlay platform defaults for ABSENT keys only — existing values always win (D-06). Platform defaults remain `UseKeychain yes` and `AddKeysToAgent yes` on darwin only, exactly what `RenderGlobalBlock` supplies today; `platform.SupportsUseKeychain(goos)` stays the gate.
4. Overlay `explicit` unconditionally — these are the user's confirmed global-SSH fixes and they always win.
5. Render in canonical order: the `IgnoreUnknown UseKeychain` directive as the body's FIRST line, then a blank line, then `Host *`, then the merged keys indented with `hostIndent`, ordered by `Policy`'s declaration order with any unrecognised pre-existing key appended after them so a hand-added directive inside the block is never dropped.
6. Compose with `filewriter.ReplaceBlock(existing, GlobalBlockName, body)`, then `filewriter.RemoveBlock(..., LegacyGlobalBlockName)` so a machine can never end up carrying both names (D-08 adoption).
7. Validate with a `Parse` round-trip before returning, exactly as `Write` already does, and return an error rather than composed bytes when it fails.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user's `~/.ssh/config` and included files → gitid parser | Untrusted, possibly hand-written, possibly hostile content crosses into the parser and the block composer. |
| gitid → `ssh` subprocess | Argument construction for `ssh -G`; a value derived from config could reach an argv slot. |
| gitid → user's `~/.ssh` filesystem | Every write in this plan mutates a file that governs the user's authentication. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Tampering | `EnsureGlobals` block composition | critical | mitigate | Compose only through `filewriter.ReplaceBlock`/`RemoveBlock` on sentinel-delimited ranges; acceptance criteria include a byte-identity assertion on hand-written content outside the sentinels. |
| T-06-02 | Denial of Service | `globalssh.RunSSHG` | high | mitigate | Every `ssh -G` runs under `exec.CommandContext` bounded by `probeTimeout`, with `Setpgid` group-kill and `WaitDelay` per the documented Linux grandchild-pipe hang; a timeout degrades to an advisory `ProbeError`, never a hang. |
| T-06-03 | Elevation of Privilege | `ssh` argv construction | high | mitigate | Arguments are passed as a slice, never a shell string (`exec.Command` bypasses the shell); the probe host is a fixed `.invalid` constant, never user input. |
