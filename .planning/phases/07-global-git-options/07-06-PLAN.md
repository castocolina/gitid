Pin every Global Git screen state against the approved dummy with a gate proven to fail on demand, assemble the review packet, and close the phase on real recorded evidence.

Purpose: this phase rewired a screen that already existed as approved demo code, which is exactly the situation where a regression is invisible — the shape stays right while the content stops matching the design that was approved. The visual-regression gate is the mechanism that makes a divergence a decision rather than an accident: every difference between the real binary and the frozen dummy must be named and classified, and a difference nobody classified must fail the build. A gate nobody has watched fail is not a gate, which is why four negative controls ship alongside it. This is also the plan that closes GGIT-01, so the exit battery here is run for real and recorded, not asserted.

|----------|-------------|
| the real binary's render → the approved design | A rewired screen can keep its shape while silently losing the content that was approved. |
| a classification entry → a real difference | An entry for a difference that no longer exists hides the next real one. |
| a gate nobody has watched fail → confidence in the gate | A vacuous gate is worse than no gate, because it is trusted. |
| a recorded battery result → what actually ran | An asserted pass is not evidence. |
