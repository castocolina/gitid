Make all twelve rows honest — real values, real provenance, real states, real explanations — and settle the three rules that keep them consistent: what counts as needing action, what a version gate is allowed to change, and what a bundle row means.

Purpose: plan 07-01 proved the architecture on the single easiest option. **Tally rule (D-10, Claude's discretion; DECIDED here, one rule for scalar and

| user-set values reported back on screen | Values read from arbitrary user config crossing into rendered rows. |
