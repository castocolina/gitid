# 09.2-01 SUMMARY — Global Git Ignore Management: Write Path End-to-End

## Overview

Phase 09.2-01 delivers a complete, tested, production-ready write path for global gitignore management through the compiled binary over a real PTY. The implementation includes backend logic (Tasks 1–2) and end-to-end proof (Task 3).

## Tasks Completed

### Task 1: End-to-End Tracer (commit 4251281)
Wired the GitIgnore screen from UI through backend seams:
- **UI Layer:** GitIgnore tab (`TabGitIgnore`) renders state with wiring-classification footer
- **View DTOs:** `GlobalGitIgnoreView`, `GlobalGitIgnoreApplyPlanView` flow state from backend to UI
- **Backend Seams:** `GlobalGitIgnoreState()`, `GlobalGitIgnoreApplyPlan()`, `CommitGlobalGitIgnore()` define contract
- **Engine Functions:** `InspectManagedBlockFile`, `ComposeGlobalGitignore`, `RenderBaselineBlock` handle file structure
- **Wiring Classification:** Four states (WiredAtManaged, KeyUnset, PointsElsewhere, NoBaselineBlock) guide ceremony and refusal logic

### Task 2: Confirmed Commit & Pair-Write (commit 92b70c9)
Writes the WHOLE `core.excludesfile` pair as one reviewed transaction with rollback on partial failure:
- **Gitignore File:** Writes managed block with normalized entries, preserving foreign lines byte-identically
- **Baseline Fragment:** Adds or verifies `excludesfile = ~/.gitignore_global` (literal tilde form) in the managed block
- **Dual-Target Plan:** When key is unset, both targets appear in the ceremony preview and receipt
- **Backup Strategy:** 
  - Gitignore file backed up only if content differs (new file gets no backup)
  - Baseline fragment backed up only if excludesfile key is being added
  - Timestamped suffix prevents collisions across multiple writes
- **Partial Failure Guard:** If gitignore write succeeds but baseline write fails, gitignore is NOT rolled back (filewriter design: all-or-nothing only at single-file level per D-09 CLAUDE.md exception)
- **Malformed-File Refusal:** Composite check refuses files with orphan sentinels, duplicate baseline blocks with disagreeing excludesfile values, or other structural damage
- **Idempotent Writes:** Identical content produces no backup and honest "no backup needed" receipt

### Task 3: Real-PTY Proof (commit 129708e)
Ten end-to-end PTY test cases at frozen 100x30 geometry prove the write path:

1. **TestGitIgnore_RealPTYSeedsFromDefaultsWhenAbsent:** Shows curated default patterns when no gitignore file exists, paired with a baseline block lacking excludesfile key
2. **TestGitIgnore_RealPTYShowsExistingManagedBlock:** Existing file with foreign lines + managed block renders block body alone; wiring sentence confirms managed-target (not wrong-target) wording
3. **TestGitIgnore_RealPTYCancelWritesNothing:** Esc dismisses ceremony without touching disk; no backup created
4. **TestGitIgnore_RealPTYConfirmWritesBlockAndBacksUp:** Existing file with foreign lines (no managed block) is backed up when confirmed; foreign content survives byte-identically; managed block inserted between sentinels
5. **TestGitIgnore_RealPTYSecondConfirmIsIdempotent:** Confirming again with unchanged content leaves file byte-identical to first write; no second backup; receipt shows "no backup needed"
6. **TestGitIgnore_RealPTYWiresExcludesfileWhenUnset:** Ceremony opens with two-target note in main view; confirms and verifies baseline fragment now carries `excludesfile = ~/.gitignore_global` (literal tilde); other baseline lines survive
7. **TestGitIgnore_RealPTYRefusesWhenNoBaselineBlock:** No managed baseline block → error state in pane, "a" key inert, no file created
8. **TestGitIgnore_RealPTYRefusesMalformedFile:** Orphan BEGIN sentinel → error state, inert apply; file byte-identical after refusal. Sub-case: two complete blocks with disagreeing excludesfile values → same refusal
9. **TestGitIgnore_RealPTYRefusesDuplicateBaselineBlock:** Two baseline blocks in fragment → malformed-file error, inert apply, all HOME files byte-identical after refusal (catches classic divergence bug: ReadBaselineState classifies from LAST block, Write rewrites FIRST)
10. **TestGitIgnore_RealPTYChangedSincePreview:** Opens ceremony (mints plan token over preimage), modifies file externally, confirms → refusal with frozen "changed since preview" copy, no receipt, no backup, external bytes untouched. Sub-case: mutates baseline fragment instead → same refusal (token includes baseline preimage)
