# Phase 9.2 — UI Design Contract

> Visual and interaction contract for Phase 9.2 (Global Git Ignore Management).
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**This document closes a governance gap, not a design gap.** Cross-AI review of
09.2-01/02/03-PLAN.md (`09.2-REVIEWS.md`) found this phase had no `UI-SPEC.md` and no
planned `UI-REVIEW.md`, unlike every other TUI-touching phase in this milestone
(Phases 3–9 all carry `NN-UI-SPEC.md` + `NN-UI-REVIEW.md`). Plan 09.2-03's Task 4 now
HALTS on this file's absence. The three plans (09.2-01/02/03) were already written and
cross-AI reviewed BEFORE this document — so this is a **derivation** of the contract
those plans already committed to, not a fresh exploration, in the same spirit as
`07-UI-SPEC.md`. Where the plans left exact copy to "Claude's discretion," this
document drafts the binding strings so the executor implements one agreed contract
instead of improvising at commit time.

This project's stack is a Go Bubble Tea v2 terminal app (not a web app) — template
sections written for CSS/web design systems are translated to their TUI equivalent
(theme roles instead of hex/CSS tokens, 100×30 fixed capture geometry instead of
responsive breakpoints), the same translation Phases 3–8's own `0N-UI-SPEC.md`
established.

## Inherited Non-Negotiables (quick reference for the executor)

Restated for convenience only — NOT decided by this document; each is cited from its
binding source and must not be re-litigated during Phase 9.2 execution.

- **Review/confirm/backup before write, no exceptions** — the SAME shared
  `ceremonyModel` every other gitid write path uses (D-04); nothing is written from
  this screen except through it.
- **Free-text editor, not toggle rows** (D-02) — no checkbox, no per-pattern
  selection model is ever added to this screen; the textarea IS the review surface.
- **Content written "as reviewed," never "verbatim"** — canonicalization happens
  BEFORE preview, never after (09.2-03-PLAN.md `<persistence_contract>`).
- **Fail closed, always with a reason on screen** — a malformed file, an unwired
  machine, a rejected sentinel, or a file changed since preview all refuse the write
  and say why in the pane; none is a silent no-op.
- **"The backup is the undo story"** — both the ceremony's backup-path promise and
  the receipt's `Backed up →` line stay first-class; an empty backup list renders the
  no-backup-needed sentence, never an invented path.
- **100×30 capture geometry** kept identical — this phase's textarea and ceremony
  both scroll inside the existing frame, never resize it.
- **Copy-freeze grep gate**, extended per this document's DRAFT strings once
  approved — `02-STYLE-SPEC.md` §6 — with the `<N>`/`<path>`/`<reason>`
  interpolations explicitly excluded (dynamic, non-contractual).
- **NO_COLOR legibility** — every state on this screen (including the new
  Error-red sentinel-rejection case) must remain fully legible under `NO_COLOR`;
  glyph + word carries the meaning, color is additive only.
