## Entry point & custom patterns

| Option | Description | Selected |
|--------|-------------|----------|
| Nested under Global Git Options, curated-only | Sub-view of the existing Global Git Options screen, toggle on/off only | |
| Nested under Global Git Options, with custom entry | Same entry point, plus freeform custom pattern entry | |
| New top-level main menu item | Standalone entry in the main menu, separate from Global Git Options | ✓ |

**User's choice:** New top-level main menu item.
**Notes:** A follow-up question then asked whether the top-level screen should be curated-only (toggle) or allow custom entry. The user's answer redefined the interaction model entirely: rather than toggle-on/off, they want a **pre-loaded textarea** the user can freely edit, add to, or customize, plus a "reset to original entries" action. A confirming follow-up question ("pre-loaded textarea, grouped under comment headers, free edit, explicit Reset to defaults, review-before-write preserved") was answered "Yes, exactly that." This is captured as D-02/D-03/D-04 in CONTEXT.md, superseding the toggle-row framing from the two earlier areas above.
