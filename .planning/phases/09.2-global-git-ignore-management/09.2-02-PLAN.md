<objective>
Make the curated catalog the one the user actually asked for, and make the rest of gitid
coexist with the fact that this content is now user-owned — without ever letting "user-owned"
become a euphemism for "gitid stopped checking".

Two halves, one commit boundary — they cannot ship apart. Extending
`DefaultGitignorePatterns()` immediately changes what doctor's excludesfile fix writes on
every machine (D-01's own "costly" reversibility note), and doctor currently demands a
byte-exact, ordered, comment-free match against that list. Ship the extension alone and every
existing user gets a false "not configured" error plus a "curated entries missing" warning,
AND the health/fixer e2e fixture — which hand-copies the old thirteen patterns — goes red
until Task 3 re-greens it. Ship the screen's editing without this and doctor's `--fix` reverts
the user's reviewed edits behind their back: the destructive false-positive loop this project
has already hit twice.

Purpose: close GIGN-01's literal pattern requirement and remove the doctor/edit conflict
BEFORE editing becomes reachable in plan 09.2-03.
Output: one curated catalog, honest doctor findings that still catch a broken machine, and a
fix that preserves user content.
</objective>
