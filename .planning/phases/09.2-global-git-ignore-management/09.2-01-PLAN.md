## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09.2-01 | Tampering | `NormalizeGitignoreLines` | high | mitigate | Reject any line beginning with a managed-block sentinel prefix before composition, so user text can never inject a nested/spoofed block that `filewriter.ListBlocks` would then mis-parse; proven by a hostile-payload unit test |
| T-09.2-02 | Tampering | `CommitGlobalGitIgnore` write path | high | mitigate | Write only through `gitconfig.WriteGlobalGitignore` -> `filewriter.ReplaceBlock` + `filewriter.Write`; foreign content preservation and the timestamped backup are asserted on real bytes by the PTY e2e |
| T-09.2-03 | Tampering | target path resolution | medium | mitigate | The target is always `filepath.Join(b.home, ".gitignore_global")`, never a view- or user-supplied path; asserted by the real-constructor wiring test |
| T-09.2-04 | Repudiation | confirmed write | medium | mitigate | The ceremony shows the exact diff of the candidate file before confirming, and the receipt names the backup actually taken |
| T-09.2-05 | Denial of Service | very large pasted content | low | accept | Bounded by terminal input; the ceremony preview is already clipped by the shared viewport |
| T-09.2-SC | Tampering | dependencies | low | accept | No new module is added: `charm.land/bubbles/v2` is already pinned in go.mod and no package-manager install runs in this phase, so the package-legitimacy gate does not apply |
